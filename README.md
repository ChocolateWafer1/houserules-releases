# House Rules releases

Downloads for **House Rules**, a poker game where you build the best hand you can and beat the house. Clear each
dealer's target, survive their house rules and climb the tables, with card skins to collect, online duels, and
Chess & Checkers.

The easiest way to play is the **Firefly Launcher**. It installs House Rules with one click, updates it whenever a new
version comes out, and plays it. Get the launcher once from
[goober-releases](https://github.com/ChocolateWafer1/goober-releases/releases) and it keeps itself up to date from
then on.

`versions.json` is the list the launcher reads. Every version's zip is attached to its
[release](https://github.com/ChocolateWafer1/houserules-releases/releases).
